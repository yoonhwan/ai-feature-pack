# GOAL — harness-ops (하네스·스킬 관리 오케 · 메인 팀) · ★불변 · 오빠 원문만 · 수정은 오빠 승인★

## 원문 (오빠 지시 2026-10-04 12:2x · planner GOAL 원문 6 첫 항 · 복붙)
> 내부 하네스, 내부 스킬스를 모니터하고 요청을 사용자에게 받아 해당 부분 바로 확인 검토하고. 실제 하네스와 스킬스를 업그레이드하고 레포에 커밋 푸시하며 전 환경에 물리적 컴퓨팅 환경에도 설치하도록 배포 발행(슬랙) 수신해 반영되 업그레이드.

## 원문 6-b (12:3x)
> 하네스 스킬 관리 오케는 메인오케들과 위성오케들에게 개선요청을 직접받아 등록관리하고 사용자와 협의해 개선하는 축도 필요함.

## 원문 5 (결합 · 머신 단위)
> 메인 하네스를 유니크하게 머신들에 완전히 독립 배분해 운용하는것.

## 상위 제약 (제품 골 · CLAUDE.md ACTIVE TRACK GOAL 바이트 일치)
목표는 빠른 유용 원문, 실시간 교정, N언어의 병렬·독립 발행, 소실·비의도 중복 없는 최종 말풍선이다.
LST ON 우선이며 LST OFF/전환과 기존 M0–M7·통합 조건도 남긴다.
단순히 실패 사례를 많이 모았다는 이유로 실험을 닫지 않는다.
