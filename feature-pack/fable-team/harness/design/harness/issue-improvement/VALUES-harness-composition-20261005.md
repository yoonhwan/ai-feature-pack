## r2 에서 바뀌어야 하는 것
- **Q1 은 추천(①)과 다르다.** 「나노 spawn 시 Issue # 필수(spawn 게이트)」 를 설계에서 뺀다. 대신: **Issue # 는 «메인 오케» 가 소유**한다 — 메인 오케가 Issue 1건을 받아 해결·완료(close 까지)하는 단위이며, 나노는 그 아래 «작업 워커»(카드 단위)로 Issue 번호를 몰라도 된다. 연결 책임(PR 「Closes #N」·진행 코멘트·완료 5항)은 메인 오케에게 둔다. B4(Issue 가 일의 정본이 아님)의 닫는 증거도 «나노 100% Issue #» 가 아니라 «메인 오케가 받은 Issue 의 Closes 연결률» 로 바꾼다. §3-2 「좌석 … Issue # 없는 좌석 0(spawn 게이트)」·§3-6 3번을 그에 맞게 수정.
- Q2·Q3·Q4·Q5 는 설계 추천안 그대로 확정 — §3·§3-6 에서 «결정 대기» 표기를 «확정» 으로.
