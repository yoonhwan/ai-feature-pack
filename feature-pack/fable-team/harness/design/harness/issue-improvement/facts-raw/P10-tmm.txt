# tmm — 모바일(Termius/SSH) 전용 tmux 좌석 TUI. 폰 60~80열 기준. fzf 기반 커서 이동·필터·미리보기.
#   tmm              TUI 피커 (↑↓ 커서 · 타이핑=필터 · Enter=attach · 아래 키 참조)
#   tmm ls [PAT]     텍스트 목록 (비대화용)
#   tmm a NAME [-i]  attach (기본 폰 크기 추종 · -i 면 데스크탑 크기 고정+점 채움)
#   tmm p NAME [N]   pane 최근 N줄 (기본 30)
#   tmm s NAME MSG   메시지 (에이전트 없는 좌석 차단 + 도달확인)
#   tmm ss           전 좌석 상태 스캔 (seat-scan)
#   tmm h            HUMAN/BLOCK/STUCK 좌석만
#   tmm save         tmuxc save
#   tmm menu         숫자 메뉴 (fzf 없을 때 폴백)
#   tmm doctor       의존성·환경 점검
#   tmm kill NAME [--yes]                좌석 종료 (tmux 세션 + 그 안의 에이전트)
#   ※ TUI 는 tmux 세션 «tmm» 안에서 뜬다(터미널이 창 리사이즈 중 pty 를 회수해도 안 죽게). 좌석에 붙었다가
#     좌석에 붙었다가 C-a d 를 누르면 피커로 돌아온다(조건부 바인딩 — 피커 세션에서는 원래대로 detach).

#   tmm dead [PAT] [--since H] [--all]   종료된 세션 목록 (재부팅·kill 로 사라진 좌석 — tmuxc 미관리 포함)
#   tmm dp NAME|SID [N]                  종료 세션의 마지막 대화 N줄
#   tmm restore NAME [--dry-run]         종료 세션 1건 복구 (resume) → attach
#   tmm restore-all [--since H] [--dry-run] [--yes]   창 안 종료 세션 «전부» 복구 — 5개씩 배치 병렬(TMM_RESTORE_BATCH), 결과 $RUN/restore-<ts>.log(ok|fail) — tmuxc restore --scan --loose 의 폰판
#   tmm idx NAME|SID [--json|--path]     세션의 대화 기록(트랜스크립트) 인덱스 경로 — 라이브·종료 공통. 에이전트가 이전 대화를 바로 찾게
#   tmm fork SRC --agent AG --model M [--name N] [--cwd C] [--effort E] [--ctx 1m] [--prompt P] [--dry-run] [--attach]
#                                        소스 대화를 «새 에이전트 세션»으로 이어받기. 동일 엔진=네이티브 tmuxc fork(전체 히스토리·부모 불변),
#                                        크로스 엔진=tmuxc open 새 세션 + 트랜스크립트 경로·발췌 주입(~/.tmm/forks). 이름 기본=소스 #N+1
#   tmm models [AG] | refresh [AG...] | find QUERY   fork 모델 별칭 — refresh 는 라이브 목록(opencode 프로바이더 접두사)에서 생성

#                                        ^F 는 어느 단계에서든 ^C(또는 이름/에이전트/모델에서 q)로 취소, 생성 중 아무 키=취소 → 피커 복귀

# TUI 키:  Enter/^E attach · ^S 메시지 · ^K 좌석닫기 · ^F fork · ^Y 대화기록 경로 · ^H 대기좌석만 · ^A 전체
