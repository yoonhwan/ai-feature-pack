## 1. 한 건 모양 (`magazine_render_cap.py` · `magazine_render_full.py`)
- 한 건 = 블록 2개: `("h3", 제목)` + `("lines", 본문 ≤3줄 + 위치 1줄)`. 그 사이에 다른 블록(경로 `p` 줄 · 목록 · 두 번째 본문)을 두지 않는다.
- 위치 줄은 **항상** 붙는다: `… 원문: <위치>`. 본문이 3줄 안에 다 들어가도 붙는다.
- 본문은 아래 «후보 줄»에서 비어 있지 않은 줄을 앞에서부터 3개 고른다.

| 절 | 제목 | 본문 후보 줄 (순서대로) | 위치 |
|---|---|---|---|
| D1 | `제목 · 팀` | 닫는 증거 첫 줄 → `why` 줄들 | 카드 경로 (DA 판정문 경로가 있으면 ` · DA <경로>`) |
| D2 | `§N 제목` | 절 본문 | 판정서 경로 `§N` |
| D3 | `판정 N` | `ts → 받는 좌석` → 쪽지 본문(relay 전문은 싣지 않음) | relay 경로(없으면 `쪽지 원문`) · `같은 번호 쪽지 N건 더` 가 있으면 위치 줄 끝에 ` · 같은 번호 N건 더` |
| D4 | `제목 (#PR) · sha10` | 커밋 본문 | `sha10` |
| D5 연 것 | `새로 연 이슈 #N 제목` | `열림` | `이슈 N번` |
| D5 닫은 것 | `닫은 이슈 #N 제목` | 닫는 댓글 | `이슈 N번` |
| D6 카드 | `[팀/상태] 제목` | `tail` | 카드 경로 (지금 있는 별도 경로 `p` 줄은 지운다 — 중복) |
| D6 외부 장애 | `외부 장애 <경로>` | 파일 본문 | 파일 경로 |
| 부록 | `<경로>` | 문서 본문 | 경로 |

- D6 의 «요청 원장 닫히지 않은 행»·«HOLD·REJECT 판정문» 목록과 D7 표는 한 행 = 한 줄 그대로 두되, 각각 20행 상한 + `외 N건`.
- `되돌림` 목록(D3)·`골좌표`·DA·옮긴 커밋 목록(D1)은 위 표에 없는 칸이라 싣지 않는다(원문 위치로 찾아감).

## 3. 시험 (`tests/scripts/test_magazine_size_cap.py` 갱신)
1. **10-10 규모 모델**을 새 함수 `real_day_model()` 로 넣는다. 닫힌 단위 41(why 12줄) · 판정 절 16(본문 30줄) · 판정 188(본문 6줄 · 홀수 번호만 relay 25줄) · 머지 87(본문 70줄) · 닫은 이슈 50(댓글 8줄) + 연 이슈 10 · 열린 카드 226(tail 3줄) · 부록 5(본문 40줄) · 1부 60줄.
   - 1부는 실제 10-10 호처럼 md 의 1부 구간(첫 `# ` ~ `# 2부` 앞)이 약 277줄이 되도록 요약 줄 수를 맞춘다(그 줄 수도 보고).
   - 기대: md 줄 수 ≤ 1,500. 측정값은 `print` 로 남긴다(보고서 증거).
   - ★1,500 을 넘으면 상수·모양을 스스로 바꾸지 말고 멈춰서 측정값(전체 · 1부 · 절별)을 보고한다★ — 숫자는 오빠 판정 821 값이다.
2. 큰 모델(지금 `big_model`)은 절마다 `외 N건` 의 N 이 정확해야 한다(20 기준 · 예: 머지 200 → `외 180건`).
3. 모든 2부 한 건: `### ` 다음 `lines` 블록이 비어 있지 않은 줄 4줄 이하이고, 마지막 줄이 `… 원문: ` 으로 시작한다.
4. 작은 모델 골든: 모양이 바뀌었으므로 골든 바이트 비교(`_magazine_small_golden.md`)는 «r1 모양 골든»으로 다시 만든다. 대신 «작은 모델 = `외 N건` 줄 0 · 본문 3줄 이하인 건은 본문 전부 보임»을 따로 확인한다.
5. 경보선 시험(`MagazineSizeError`) · 쉬운 판 12장 시험은 그대로.
6. `python3 -m pytest tests/scripts/ -q -k magazine` — 실패는 기준선의 13건만이어야 한다. 그 13건 목록을 보고서에 그대로 다시 적는다.
