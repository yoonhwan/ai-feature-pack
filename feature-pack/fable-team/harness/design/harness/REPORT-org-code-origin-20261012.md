## 3. 왜 놓쳤나 (질문 ②) — 구조 2개
1. **유예가 «주석»에 산다**: 「별건·적용 후·나중에」는 코드 안 글자라 카드·이슈·현황판·뉴스 어디에도 안 뜬다. 10-01 구조 분리 때 그 줄을 옮긴 좌석도 «이동»만 했다 — 읽어도 할 일로 바뀌지 않는 꼴.
2. **«건너뜀»이 초록으로 읽힌다**: 필수 검사 job 이 `always()` 없이 앞단 skipped 를 상속받아 skipped 되고, summary 는 `always()` 라 초록. 사람은 run 의 conclusion(success)만 본다(10-11 5회 전부). 검사가 «안 돈 것»과 «통과한 것»이 같은 색.
