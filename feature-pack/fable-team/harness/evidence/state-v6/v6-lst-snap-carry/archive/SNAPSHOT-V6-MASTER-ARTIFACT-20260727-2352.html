7-1. 노드 상태와 완료 증거

MISSING → IMPLEMENTED → TESTED → LIVE_OBSERVED → COMPLETE
                                      ↘ BLOCKED

각 gate ledger는 canonical edge / implementation SHA / RED / GREEN / negative·mutation / real boundary / same-ID live trace / checker / DA / predecessor / attempts / blocker를 기록한다. 한 칸이라도 없으면 COMPLETE가 아니다.

7-2. 수렴 규칙

  • 한 번에 mutable gate 하나만 둔다.
  • 동일 실패 유형 2회째에는 patch를 중단하고 architect 재설계를 수행한다.
  • 같은 blocking condition 3회째에는 BLOCKED로 닫고 HELM/owner 결정을 받는다.
  • E2와 final scenario matrix 이전에는 V6 COMPLETE 표현을 사용하지 않는다.
