# r945 r6 요약 — git 호출을 한 함수로(어떤 rc≠0 도 «판정 불가») + 동결 기대 복원(arch 157 반송서 · 오빠 결정 3)

## 바뀐 것(구현 교체 1커밋)
- `gitfail()` 신설 = 실패의 «공용» 처리 — shell_scan 의 지역 `und`/`ucnt` 에 «판정 불가 <경로:단계>» 를 더한다. 호출부는 그 워크트리를 건너뛴다(껍데기 0 · HIL 0 · 삭제 0).
- shell_scan 의 git 호출 4자리 전부 git7 경유 + 실패 분기 통일: ①워크트리 설정 조회(:config) ②공용 `worktree list`(:worktree-list) ③`ls-tree`(:ls-tree) ④`ls-files -d`(:ls-files) + ⑤`sparse-checkout list`(:sparse-list).
  - 조용한 «껍데기 0» 과 «일반 워크트리로 후퇴» 분기가 사라졌다(r5 는 설정 실패를 일반 규칙으로 흘려 껍데기 1, 공용 목록 실패는 조용한 0).
  - `config --bool --get` 의 rc 1 = «키 없음 = 일반 워크트리»(정상) · rc ≥ 2 = 판정 불가로 갈랐다.
- 동결 기대 복원: sparse 표식이 true 면 패턴 파일을 읽을 수 있는지 1회 묻는다 — 패턴 파일이 폴더면 git 은 rc0 + 경고만 내므로 «rc≠0 또는 경고» 를 판정 불가로 본다(da4 = 동결값 1).
- 판정 불가 줄에 «경로:단계» 를 적는다(어느 호출이 실패했는지 사람이 바로 안다).
