## 고침 1곳 (로직 추가 0 · 함수 호출 1곳)
같은 sha·같은 주인 «재사용» 조건에 verify_complete(그 사본) 를 더한다 — HEAD 일치 ∧ 체크아웃 규칙 일치 ∧ 완전(HEAD == 요청 sha ∧ git status 깨끗) 일 때만 재사용.
완전하지 않으면 그 줄을 건너뛰고 WARN 1줄(«불완전 사본 건너뜀 …») + 새 사본 생성. 삭제 0 · 장부 줄 유지.
구현: verify_complete 를 경로 인자를 받는 공용 함수 1개로 올리고(전에는 DEST 전용 내부 함수) 생성 뒤 확인과 재사용 판정이 같은 함수를 쓴다.
