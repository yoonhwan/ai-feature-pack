# <팀> 트랙 — 이 폴더 하나로 시작한다

처음 읽을 순서: ① `GOAL-<팀>.md`(골 원문) → ② `GUIDE-<팀>.md`(이 팀만의 규칙) → ③ `STATE.md`(재개용 요약) → ④ `indices/진행/` 카드.
원리 세 줄: 작업 = 카드 파일 1개 · 상태 = 카드가 들어 있는 폴더 · 좌석은 갈아 끼운다(파일이 상태).

## 파일 지도

| 파일 | 역할 | 갱신 |
|---|---|---|
| `GOAL-<팀>.md` | ★불변★ 골 원문 | 오빠 승인 때만 |
| `GUIDE-<팀>.md` | 이 팀만의 규칙(전역 규칙은 링크만) | 오빠 검토 때만 |
| `STATE.md` | 재개용 요약 1장 + 링크만 | 팀 오케 |
| `plans/` | 설계·기획(DESIGN-* · SPEC-* · PLAN-* · DIAG-*) | 추가 |
| `indices/{inbox,대기,진행,완성}/` | 할 일 카드(1장 = 1단위 · 상태 = 폴더) | 매 단위 |
| `orders/` | 발주서 원문 | 추가만 |
| `reviews/` | DA-BRIEF-* · DA-* · VERDICT-* | 추가만 |
| `evidence/` | 실측 산출 | 추가만 |
| `closeout/` | 마무리 정본 CLOSEOUT-<단위>-<날짜>.md | 단위가 끝날 때 |
| `archive/` | 옛 파일(이동만 · 삭제 0) | 이동만 |

현역 원장(요청 원장·랜딩 원장 등 도구가 경로를 박아 쓰는 파일)은 바닥에 두고 위 표에 «현역 원장» 으로 한 줄 등록한다 — 등록하지 않은 바닥 파일은 `ft-team-map-lint.sh <팀>` 이 정리 후보로 알린다.
