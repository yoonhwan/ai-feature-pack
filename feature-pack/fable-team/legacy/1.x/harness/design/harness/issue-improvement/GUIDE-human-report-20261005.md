# GUIDE — 사람이 읽는 보고 (조각 P4 r2 · 2026-10-05 · arch#1 · DA r1 HOLD 3 반영)

> 골(GOAL-harness.md 「모니터」 축): 오빠가 **읽고 판단할 수 있는** 보고가 나가야 모니터가 성립한다. 발주 = ops#2 ORDER-human-report-guide(#56987). 오빠 말: 「지금 메세지 사람이 읽지 못하는 메세지임」.
> 적용 대상 = 오빠가 읽는 모든 글(pane 보고 · 슬랙 · 인터뷰 머리글). 세션끼리 주고받는 mbox 는 대상 아님(기계가 읽는다).
## 1. 틀 (순서 고정 · 기본 10줄 이내)
1. **결론 한 줄** — 쉬운 말. 「무엇이 어떻게 됐다」.
2. **오빠가 할 일** — 없으면 「없음」. 있으면 **질문 1개**만, 선택지는 번호로. 질문은 이 칸에만 두고 다른 칸에 질문을 섞지 않는다.
3. **바뀐 것** — 3줄 이내. 한 줄에 한 가지.
4. **근거** — 항상 맨 끝 한 줄(커밋 번호·파일 경로·메시지 번호). 질문이 있어도 근거는 그 뒤 맨 끝이다. 본문 문장 안에 식별자를 넣지 않는다.
## 2. 말 규칙
- 처음 나오는 내부어는 **괄호로 한 번** 풀이한다. 그 뒤로는 쉬운 말만 쓴다.
- 숫자에는 **뜻을 붙인다**: 「28 : 2」 → 「진행 중 표시 카드 28장, 실제로 일하는 세션 2개」.
- 한 메시지는 **한 가지 성격**: 결정 요청(질문 1개로 끝) 또는 상태 보고(질문 0). 별도 발견은 다른 메시지로 보낸다. 사실과 추론을 섞지 않는다 — 센 숫자만 쓰고 세지 않은 것을 단정하지 않는다.
- 표는 3열까지 · 괄호 안에 괄호 금지 · 화살표·약어·영문 식별자는 근거 줄로 보낸다.
| 내부어 | 쉬운 말 |
|---|---|
| 오케(오케스트레이터) | 팀 책임자 세션 |
| 나노 | 작업 담당 세션(한 가지 일만 맡음) |
| arch / DA / tester / checker | 설계 담당 / 반박 검토 담당 / 시험 담당 / 확인 담당 |
| 카드(인덱스) · 대기/진행/완성 | 일감 쪽지 · 아직 안 시작 / 하는 중 / 끝남 |
| 슬롯 · 예약석 | 동시에 열 수 있는 작업 세션 자리 · 급한 장애용으로 비워 둔 자리 |
| 보류 | 하던 일을 멈추고 세션은 살려 둔 상태 |
| press | 실제 소리를 넣어 돌리는 통역 시험 |
| 랜딩 · sha | 코드를 본선에 합침 · 그 합친 지점의 번호 |
| 워크트리 | 작업용 코드 복사본 폴더 |
| mbox · seq | 세션끼리 쪽지함 · 쪽지 번호 |
| HOLD / APPROVE | 반박 검토에서 「고칠 것 있음」 / 「통과」 |
| 정지 레디 | 하던 일을 저장하고 멈춘 상태(언제든 다시 시작 가능) |
