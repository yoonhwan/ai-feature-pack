## 차이의 정체(줄 단위 대조) — 코드 때문이 아니라 «git 실재 여부» 때문
- test_board_publish_norm: 후판에만 있는 한 줄 = 'ⓜ 발행 본문(published.txt) 옛·새 스크립트 바이트 동일' PASS.
  이 칸은 옛 판을 git 에서 꺼내 비교한다 — /tmp 사본(비 git)에서는 칸 자체가 안 돈다. 즉 후판 슬랙 본문이 옛 판과 바이트 동일하다는 증거가 하나 더 붙은 것.
- test_inbox_watch: 전판만 FAIL 3 + 1 = LIVE_BIN 풀이 실패(/tmp 사본이 git 밖) + '짝 불일치 ft-mbox.sh'. 후판은 git 안이라 그 3+1 이 PASS 로 바뀐다. 남은 FAIL 은 이 카드 무관.
- test_inbox.sh(78/0) · test_board_sh 외 전부 = 전판·후판 동수·동줄.
