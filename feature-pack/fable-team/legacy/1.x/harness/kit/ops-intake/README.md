# kit/ops-intake — #howto-talk-ops 접수 도구 (하네스팀 몫)

사용자가 슬랙 `#howto-talk-ops` 에 쓴 글 → mini 의 aina 접수 카드 → 이 맥 접수 팀장 → byz 이슈팀 등록 → 같은 스레드로 번호·상태 회신.
이 폴더는 그 사슬의 **기계 부품**이다(팀·좌석·명부는 플래팀 · 설치·시험은 r956 h-A·h-B·h-C · 기획 정본 = 멀티호스트 팀 `docs/multihost/DESIGN-ops-intake-20261026.md`).

## 계약(바꾸면 시험도 같이 고친다)

1. **비밀 가림은 공용 함수 하나** — `ops_intake_common.mask_text()` 가 `harness/bin/ft_secret_shapes.mask()` 를 **그대로** 부른다(복사 0). 꼴 목록은 이 폴더에 없다. 공용 규칙표 `kit/slack-mirror/post_guard.SECRETS` 는 ① **판정**(`detect_raw`) ② **머리표 가림** 에만 쓴다 — 이름+구분자(`= : /`)로 끝난 머리표는 뒤 첫 덩어리를 통째로 `***`(머리표만 가리면 값이 남는다 · DA⑥ r4 반례 1). 개인정보 전화·이메일 2규칙만 이 폴더에 더한다. 어느 모듈이든 못 찾으면 «판정 불가 = 차단»(rc2).
1-1. **정규화 먼저, 검출 나중** — 모든 입력은 검출·마스킹 *전에* 제어문자·폭 0 문자 제거 · 탭/개행 → 공백 1개로 정규화하고, 마스킹 뒤에는 글자를 더 바꾸지 않는다. 쪼갠 토큰(CR·LF·탭·ZWSP·제어문자)은 공백을 지운 이웃 덩어리를 붙여 보는 창(2~4개)으로 가린다.
1-2. **개인키는 블록 통째 삭제** — `-----BEGIN…PRIVATE KEY-----` 부터 `-----END…` 줄까지 지운다(END 가 없으면 끝까지). 줄 단위 마스킹은 본문을 남긴다(DA⑥ r4 반례 2).
1-3. **가림 뒤 공용 판정 한 번 더** — 남는 것이 있으면 **접수 거절**(rc2 · 카드 0 · 쪽지 0). 조용한 통과 0.
2. **`secrets_masked: <정수>` 는 필수 칸** — 이 맥은 «머리 블록(첫 `---` 앞)» 에서 그 키 줄이 **정확히 1개 · 0 이상 정수** 일 때만 인정한다. 0개 · 2개 이상 · 정수 아님 · 본문 쪽에 심은 같은 키 = 판정 불가 = 등록 차단(조용한 통과 0).
2-1. **한 칸 = 한 줄** — 사용자 값의 줄바꿈은 `\n` 글자로 바꿔 카드에 넣는다. 안 바꾸면 그 줄이 머리 칸(`secrets_masked`)을 위조한다(DA⑥ r1 ①).
3. **원본 보존 0** — 이 맥은 카드를 임시 파일로 받아 재검사하고 그 자리에서 지운다. 걸린 카드는 `quarantine/` 에 `[제거]` 사본만, 같은 사본을 mini 카드로 덮어쓴다.
4. **게시 문장 검사는 정본 규칙표 재사용** — `kit/slack-mirror/post_guard.py` 의 `SECRETS`·`INTERNAL`. 사람 채널 판정(명부 조회)은 mini 에 명부가 없어 쓰지 않고 «항상 사람 채널» 로 건다. 이 폴더가 더 막는 3가지: 커밋 sha 꼴 · **절대경로 꼴**(`/a/b…`·`~/a…`) · **비밀 종류 낱말 + 가림 표시**(«토큰 ***» 처럼 우리가 무엇을 가렸는지 알려 주는 문장).
5. **슬랙 호출은 `mirror_lib.post` 재사용** — 7초 상한·재시도 1 이 그 안에 있다(하드 룰 12).
6. **쪽지 형식·잠금은 `ft-mbox.py` 재사용** — 이 폴더가 쪽지 파일을 직접 쓰지 않는다.
7. **절대경로 기본값 없음** — 이 맥 쪽지함·장부 경로는 `FT_MBOX_DIR`·`SAT_STATE`, ssh 대상은 `MINI`/`SAT_SSH`. 없으면 리포 루트 추정, 그것도 없으면 중단.
8. **쪽지함 큐 ≥10 이면 pull 보류** — **쪽지 1건마다 큐를 다시 세고**, 넘으면 남은 건은 보내지 않는다(원격 ack 0 · 다음 패스). 로그 `HOLD queue=<n> remaining=<m>` 1줄, rc5.
9. **외부 호출 1회 7초** — ssh·scp·원격 파이썬 전부 7초 상한. 넘으면 rc≠0 「7초 초과(<단계>)」. 25초 같은 긴 상한은 두지 않는다.
10. **본문 끝 표식** — 게시 본문 끝에 `· ops-<base36 5자>` 를 붙이고, 검사는 «표식 붙인 최종 본문» 에 건다. 표식은 자기 검사(sha·경로·이름:값)에 안 걸리는 꼴이라 정상 쪽지가 자기 표식에 막히지 않는다.
11. **게시는 «기록 먼저, 보내기 뒤»** — 원장(`state/posted.json`)에 `sending` 을 먼저 쓰고, 보낸 뒤 `sent` 로 바꾼다. 보내기가 실패하거나 벽시계를 넘기면 `failed`. 재실행에서 `sending`·`failed` 를 보면 **다시 보내지 않고** 그 스레드에 같은 문장(표식)이 있는지 조회한다 → 있으면 `sent` 로 맞추고 쪽지를 지운다 · 없거나 조회가 실패하면 «확인 불가» ERROR 1줄 + 쪽지를 남긴다(rc5). 계약은 «두 번 나감 0» 이 «한 번 못 나감 0» 보다 앞이다(DA⑥ r2 반례 2). 확인 불가 쪽지는 **그 건만 건너뛰고 다음 쪽지로 간다**(ack 0 유지 · 머리막힘 0) · ERROR 줄에 사람이 푸는 손(원장에서 그 키 항목 제거)을 적는다.
12. **원장 단일 실행 잠금(fcntl.flock)** — 두 프로세스가 겹쳐 돌아도 «보내는 중» 판정이 갈리지 않는다.
13. **접수 쓰기도 같은 잠금** — 한도 확인 → 번호 → 카드 쓰기 → 쪽지 → 원장을 한 flock 안에서. 임시 파일 이름은 프로세스마다 다르다(`mkstemp`) — 같은 `.tmp` 를 둘이 쓰면 한쪽 JSON 이 깨진다.
14. **외부 호출은 «벽시계» 7초 하나** — 연결·읽기·종료를 전부 포함한다. 입구에서 마감 시각을 잡고, 감시 타이머가 마감 순간 소켓을 shutdown 해 막힌 recv 를 끊으며(1바이트씩 흘리기·4초 청크 + 8초 종료 둘 다 차단), 읽기가 끝난 뒤에도 마감을 한 번 더 본다. 넘으면 `sent` 0 · 원장 `failed` · 다음 패스. ssh 는 프로세스 timeout(7초)으로 끊는다.
