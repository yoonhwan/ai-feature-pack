## 1. 좌석 계약 (DA 좌석)

| 항목 | 값 |
|---|---|
| 산출 | 반례 묶음 + 판정 1줄. 개선 제안·감상·코드 0 |
| 판정 값 | 카드 = `HOLD` · `APPROVE` · `[확인 필요]` · 반례 1건 = [수용] · [거절] · [범위 밖] — 두 층 모두 세 값 밖 금지(정본 §핵심 3) |
| 반례 꼴 | `<기준번호> 입력/줄 → 깨진 계약 · 재현 명령 · 기대/실제` |
| 제출 시점 | **회차 1에 전수**. 회차 2는 «지난 반례 처리 확인» 만 |
| 받아야 할 것 | 카드 §구현 범위 · 번호 붙은 수용 기준 · 계약/시험 · 지난 반례 목록 |
| 없으면 | 반송이 아니라 «입력 부족 <무엇>» 1줄로 arch 에 반송 |
| 코드·증거 줄 | 쓰지 않는다(정본 §6) |

## 2. 발주·반송 문구 (복사해서 쓴다)

- arch → DA 발주: `[발주] 카드 <경로> · 수용 기준 C1..Cn (이 목록 밖은 판정 대상 아님) · 지난 반례: <없음|seq/path> · 회차 <n>/3`
- DA → arch 반송: `[판정] HOLD 회차 <n>/3 · 반례 R1..Rk (전수) · 범위 밖 메모 M1.. · 중복 제외 항목`
- arch → 나노 고침 발주: `R1..Rk 전부 고침 + 각 반례 재현 명령 실행 결과를 증거 줄에 · 기준 추가 금지`
- 3회 초과 필요 시: `[HIL] 카드 <경로> 반송 4회 필요 — 사유 <표면 변경|기준 모순> · 선택지 <상한 예외|카드 분할|중단>`

## 3. 상한과 예외

- 카드당 DA `HOLD` 상한 = **3**. 3회 HOLD 뒤 arch 가 오케(`[HIL]`)로 올려 오빠 판정을 받는다.

> **3회 HOLD 뒤 = 오빠 인터뷰 (DA 흐름 ①→수정→②→최종 수정→③ · ③은 ①② 동결 반례 안에서만 · 새 반례는 [범위 밖]) (필수 · 오빠 10-27 00:5x «아키가 못하면 꼭 나에게 인터뷰를 과정해서 넘길지 다른 해결법이 있는지 설명하고 인터뷰해서 정리를 만드는것»)** — 반송 3회 뒤에도 arch 가 못 풀면 arch 가 인터뷰 꾸러미 1장을 만든다: ①무엇이 3회 막혔나(반례 원문) ②선택지 = 넘김(다른 팀·좌석) · 다른 해결법 2~3개 · 범위 줄이기 · 보류 — 각각 장단·비용 ③추천 1. 경로 = arch → planner → desk → 오빠 슬랙(번호 선택지) → 오빠 답을 카드에 «결정:» 1줄로 적고 그대로 진행. 인터뷰 없이 4번째 DA·재설계를 돌리지 않는다.

> **오빠 결정 10-27 01:1x (desk #171354 · 개선안 PR 3699 · 지금부터 적용)** — D1 보류 3회 뒤 = 위 인터뷰 · 결정 뒤 반례 집합·계약 동결, 구현만 교체(집합을 바꾸려면 새 카드). D2 카드 APPROVE = [수용] 반례 0 ∧ 미시험 기준 0 · [범위 밖] 은 카드 판정 밖 · 미시험이 남으면 `[확인 필요]`. D3 **카드당 DA 호출 상한 3회**(반송 상한과 다른 단위 · 승인·확인 필요 호출도 셈 · 4번째 호출은 없고 3회 HOLD 뒤 = 인터뷰). D4 카드 크기 게이트 = 구현 범위 ≤3항목 · 바뀌는 파일 ≤3 · 시험 묶음 ≤2 · 반례 집합 절과 계약↔시험 대응표 없는 카드는 spawn 0(도구 강제는 하네스 카드 · 그 전에는 arch 가 카드 작성 때 지킨다). D5 리서치 나노 시점·모델 상향은 하드 룰 14 옛 문장 그대로.
- 재설계로 카드 표면을 바꾼 경우도 반송 1회로 센다(하드 룰 14 의 «재설계» 가 상한을 우회하는 구멍을 막는다).
- 설계·조사 카드(수용 기준이 없는 카드)는 상한 대상이 아니다. 대신 «질문 1개» 로 좁힌다.

## 4. 기록 (카드 증거 줄 옆에 남긴다)

```
DA: 회차 <n>/3 · 판정 <HOLD|APPROVE|확인 필요> · 반례 <k>건(전수) · 범위 밖 <m>건 · 중복 0
```

지표(팀 단위 누적) = 반송 횟수 · 첫 판정 APPROVE · 반례 중복률 · 반송→재판정 간격 · 착지 후 되돌림. 정본 §5 와 같은 표를 쓴다.

## 5. 왜 이렇게 하는가 (수치 3개)

- 평가자 범위를 고정하면 코멘트 50% 가 해소된다 (Google AutoCommenter · arXiv 2405.13565).
- 전수·단일 패스가 다회 루프보다 정확하고 싸다: 32.00%/$0.70 vs 27.33% (Agentless · arXiv 2407.01489).
- 외부 신호 없는 자기수정은 성능이 오히려 떨어진다 (ICLR 2024 · arXiv 2310.01798) → 반례는 실행 가능한 신호여야 한다.
