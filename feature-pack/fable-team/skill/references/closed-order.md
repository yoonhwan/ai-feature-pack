# 닫힌 발주 — 열린 지시가 라운드·질문 무한 루프를 만든다

> 오빠 11-06 «이래서 DA 만 가면 끝이 안나던 거였네» · «이거 정상화완전히»
> 근거 실측 = `design/journey/DA-*.md` 39건 + codex rollout 집계

## 증상 (실측)
| 대상 | 값 |
|---|---|
| DA 카드 harness-0.5-row2 | **10 라운드** |
| DA row5 / 0.4-unit1 / row3 / row1 | 6 / 5 / 3 / 3 |
| 서포트 세션 툴호출 | 14건 = **질문 10 + sleep 4** (실행 판단 0) |

## 원인 3겹
1. **지시가 열려 있다** — «반례를 찾아라» / «막힌 것을 찾아라». 열린 집합은 항상 하나 더 나온다.
2. **집행 권한이 없다** — DA는 설계만, 서포트는 랜딩 금지 → 결론 대신 «보류/질문» 으로 끝난다.
3. **산출물이 다음 라운드의 입력** — DA 문서가 다시 반박 대상, 보류가 새 반례의 씨앗.

## 처방 — 발주문 5칸
| 칸 | 내용 | 예 |
|---|---|---|
| ① 대상/반례 집합 동결 | 이번 라운드 유효 범위 | «동작 반례만. 형식·문구·줄 수는 범위 밖» |
| ② 판정 기준 | 통과/탈락 조건 | «재현 명령 붙은 동작 반례 0 = 통과» |
| ③ 상한 | 라운드·호출 수 | «카드당 3라운드. 4번째는 DA 0, 오빠 인터뷰 1» |
| ④ 종료 조건 | 끝낼 수 있는 상태 | «반례 0 또는 결정 위임 1줄. 그 외로 끝내지 않는다» |
| ⑤ 다음 수 | 누가 무엇을 | «누가·무엇을·완성 전/후 1줄» |

## 부칙 2
- **질문 상한**: 좌석당 1턴 질문 1회. 그 이상은 파일에 «선택지 3개 + 추천 1개» 로 적고 다음 항목.
- **sleep 금지**: 대기 대신 상태를 파일에 쓴다. 대기를 산출물로 만들지 않는다.

## 검사 방법
- 발주문에 5칸이 있는가 (문자열 검사)
- 결과물의 라운드 수 (DA 문서 수)
- 세션의 질문 툴 호출 수 (rollout/jsonl 집계)

## 하지 말 것
- 반례 자체를 없애지 않는다. **집합을 동결하고 상한을 두는 것**이 요점.
- 5칸을 형식만 채우면 빈 칸이 생긴다. 검사기는 칸 존재만 보고, 품질은 라운드 수로 사후 측정한다.
