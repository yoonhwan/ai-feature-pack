## 핵심 3줄
1. 5x 는 Pro 의 5배를 쓰고 5배를 낸다 — 1배당 값이 Pro 와 같다.
2. 20x 는 5x 의 4배를 쓰고 2배를 낸다 — 같은 돈으로 받는 가치가 2배다.
3. 같은 토큰이면 256k 세션은 1M 세션보다 4배 많이 대화한다.

## 기준
- 상한 계산 순서(주간 기준): ①실측 5x 주간 상한 = 가중 4.2억(5h 창 6,000만 × 7) ②하루 최대 = 주간 ÷ 7 = 가중 6,000만 ③한 달 최대 = 하루 × 30 = 주간 × 30/7(약 4.3주) · 5h 창만 보면 하루 약 4.8창이라 더 쓰지만 주간 상한이 먼저 걸리므로 매일 고르게 쓸 때 실제 상한 = 주간 ÷ 7
- API 정가(100만 토큰당 · 오빠 제공 11-11): 입력 $4 · 출력 $20 · 캐시 읽기 $0.20 · 캐시 쓰기 5분 $5 / 1시간 $8(계산은 1시간) · 환율 1달러 = 1,400원
- 대화 1회 = 실제 약 150,332 토큰(캐시 읽기 99%) = 가중 19,519 = API 약 68원($0.0483)
- 하루 최대 = 5x 5시간 창 실측 «가중 6,000만»(BYZ-Agents 리포 design/harness/ANALYSIS-token-waste-and-reload-cost-20261110.md 14행 · ±30%)을 하루 환산 값으로 · Pro = ÷5 · 20x = ×4
- 가중 = 입력 1 · 캐시 읽기 0.1 · 캐시 쓰기(1h) 2 · 출력 5 (ctx-burn 가중 그대로)
- 세션 «개분» = 하루 최대 토큰 ÷ 창 크기(1M=1,000,000 · 512k=512,000 · 256k=256,000) · 대화 1회마다 세션 전체를 다시 읽는다
- 실사용 = `ctx-burn --runtime all --hours 24 --json`(2026-11-11 18:4x) + pi 세션 jsonl usage 합(claude 모델 20,527요청): 입력 43,018 · 출력 9,655,259 · 캐시 읽기 3,052,627,879 · 캐시 쓰기 23,546,882
