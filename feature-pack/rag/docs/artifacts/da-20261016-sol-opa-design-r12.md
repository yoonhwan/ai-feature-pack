## Minor 1 — 수동 a~g가 G4와 완전히 같은 계약으로 적히지는 않았다

:75의 «축약 금지·G4 동등» 원칙과 기존 함수를 재사용하는 방향은 수용한다. 다만 :79의 **순서 포함**은 실제 gate_n4의 정렬 목록 비교보다 강하고, :80의 **부하 길이 3 수치**에는 유효한 **null**이 빠졌다. 합성 확인에서 순서를 뒤집은 정상 단계 배열과 load_before/load_after=null은 실제 G4를 통과한다. 따라서 문장만 따라 수동 판독하면 정상 자료를 부적격으로 읽을 수 있다.
